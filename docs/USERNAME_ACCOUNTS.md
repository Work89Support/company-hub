# คู่มือบัญชีผู้ใช้ Company Hub

เวอร์ชันเอกสาร: **12 ตุลาคม 2569**
ขอบเขต: หน้า **บัญชีของฉัน**, หน้า **บัญชีทีม** และขั้นตอนดูแลชื่อผู้ใช้ แผนก สิทธิ์ และรหัสผ่าน

## 1. บัญชีของฉัน

หน้า **บัญชีของฉัน** แสดงข้อมูลที่ระบบใช้จริงในรูปแบบเดียวกันสำหรับทุกแผนก ได้แก่

- ชื่อที่แสดงและสถานะบัญชี
- แผนกหลักและแผนกที่ได้รับสิทธิ์เพิ่มเติม
- ตำแหน่งและระดับสิทธิ์ เช่น พนักงาน หัวหน้างาน ผู้บริหาร หรือผู้ดูแลระบบ
- วิธีเข้าสู่ระบบ: ชื่อผู้ใช้ Company Hub หรืออีเมลเดิม

### บัญชีชื่อผู้ใช้ Company Hub

เจ้าของบัญชีสามารถแก้ชื่อที่แสดง ใส่อีเมลติดต่อ และเปลี่ยนรหัสผ่านด้วยรหัสปัจจุบันได้จากหน้านี้ การเปลี่ยนชื่อไม่ทำให้งานหรือประวัติหาย เพราะข้อมูลผูกกับรหัสบัญชีภายในเดิม

อีเมลติดต่อเป็นข้อมูลประกอบ ยังไม่ใช้กู้รหัสผ่านอัตโนมัติจนกว่าจะมีกระบวนการยืนยันอีเมลในระบบ

### บัญชีอีเมลเดิม

ระบบจะแสดงอีเมล แผนก ตำแหน่ง สิทธิ์ และสถานะให้อ่านได้ชัดเจน แต่ไม่เปิดช่องเปลี่ยนชื่อหรือรหัสผ่านจากหน้า Company Hub หากต้องแก้ชื่อ อีเมล รหัสผ่าน หรือแผนก ให้ติดต่อผู้ดูแลระบบเพื่อยืนยันเจ้าของบัญชีก่อน

## 2. บัญชีทีมสำหรับผู้ดูแล

หน้า **บัญชีทีม** แสดงรายชื่อเป็นตารางและแบ่งกลุ่มตามแผนกหลัก แต่ละแถวมีข้อมูล:

1. ชื่อพนักงานและชื่อเข้าใช้
2. อีเมลติดต่อ พร้อมป้ายเมื่อเป็นอีเมลที่ใช้ร่วมกัน
3. แผนกทั้งหมดที่บุคคลนั้นรับผิดชอบ
4. ตำแหน่งและระดับสิทธิ์
5. สถานะบัญชี: พร้อมใช้ รอตั้งรหัส หรือปิดใช้งาน
6. ปุ่มแก้แผนก/หน้าที่ และออกรหัสใหม่

ผู้ดูแลค้นหาด้วยชื่อ ชื่อเข้าใช้ หรืออีเมล และกรองตามแผนกหรือสถานะได้ หนึ่งบัญชีสามารถอยู่หลายแผนกโดยยังคงเป็นบุคคลเดียวและมีประวัติเดียว

## 3. ขั้นตอนสร้างและดูแลบัญชี

1. ตรวจชื่อ อีเมล แผนก ตำแหน่ง และบทบาทจากข้อมูลที่ยืนยันแล้ว
2. หากเป็นพนักงานใหม่ ให้เปิดส่วน **สร้างบัญชีจากรายชื่อเดิม** และตรวจแต่ละรายชื่อก่อนสร้าง
3. ส่งชื่อเข้าใช้และรหัสครั้งแรกให้เจ้าของบัญชีเป็นการส่วนตัว รหัสจะแสดงครั้งเดียวและมีอายุจำกัด
4. เจ้าของบัญชีต้องตั้งรหัสใหม่ก่อนเปิดข้อมูลงาน
5. ผู้ดูแลอนุมัติเครื่องและ IP ตามนโยบายของบริษัท
6. ทดลองเปิดเมนูตามสิทธิ์และยืนยันว่าเห็นเฉพาะแผนกที่ได้รับมอบหมาย

ชื่อกลุ่ม ชื่อสะกดใกล้เคียง หรือรายการที่ยังระบุตัวบุคคลไม่ได้จะไม่ถูกสร้างอัตโนมัติ ต้องตรวจและยืนยันก่อนเสมอ

## 4. การเปลี่ยนแปลงข้อมูล

- **แก้ชื่อ:** ใช้บัญชีเดิม งานและประวัติยังอยู่ครบ
- **ย้ายหรือเพิ่มแผนก:** ใช้ปุ่ม **แก้แผนก / หน้าที่** และตรวจเมนูหลังบันทึก
- **ออกรหัสใหม่:** ทำเมื่อยืนยันเจ้าของบัญชีแล้ว รหัสเดิมและเซสชันเดิมจะถูกยกเลิกตามนโยบายความปลอดภัย
- **ปิดใช้งาน:** ใช้เมื่อบุคคลไม่ได้ปฏิบัติงานแล้ว โดยเก็บประวัติเดิมไว้
- **อีเมลใช้ร่วม:** แสดงป้ายกำกับในตารางเพื่อให้ผู้ดูแลตรวจชื่อบุคคลก่อนทำรายการ

## 5. ข้อควรระวัง

- ห้ามส่งรหัสผ่านในกลุ่มแชตหรือเอกสารรายชื่อรวม
- ห้ามสร้างบัญชีซ้ำเพื่อแก้ชื่อหรือย้ายแผนก
- ห้ามเดาตัวบุคคลจากชื่อใกล้เคียงหรืออีเมลที่ใช้ร่วมกัน
- การเปลี่ยนสิทธิ์ต้องตรวจทั้งแผนกหลัก แผนกเพิ่มเติม และระดับบทบาท
- จำนวนบัญชีและสถานะจริงให้ตรวจจากหน้า **บัญชีทีม** เพราะเปลี่ยนได้ตลอดเวลา

## 6. การตรวจหลังแก้ไข

หลังแก้บัญชี ให้ทดสอบด้วยบัญชีที่ได้รับอนุญาตโดยตรวจว่า:

- เข้าสู่ระบบและตั้งรหัสครั้งแรกได้
- หน้า **บัญชีของฉัน** แสดงชื่อ แผนก ตำแหน่ง และวิธีเข้าใช้ถูกต้อง
- เมนูและข้อมูลตรงกับสิทธิ์
- งานเดิมและประวัติยังอยู่ครบ
- บัญชีหลายแผนกค้นพบได้จากทุกแผนกที่ได้รับสิทธิ์

รายละเอียดเทคนิคของการสร้างบัญชี การเพิกถอนเซสชัน และ RLS อยู่ใน Migration และ Edge Function `company-accounts` ของโครงการ เอกสารนี้เน้นขั้นตอนที่ผู้ใช้และผู้ดูแลต้องปฏิบัติในหน้าระบบปัจจุบัน
