## ฟังก์ชันและผลทดสอบ

- ฟอร์มกิจกรรมตรวจเจ้าของ แผนก วันที่ เวลา สถานะ และผลลัพธ์ตามสถานะ บันทึกสำเร็จแล้วเปิดหน้าเลือก KPI
- เพิ่มแท็ก KPI ของกิจกรรม งานมอบหมาย กราฟิก และปัญหา ใช้ foreign key จริง ตรวจสิทธิ์ต้นทาง และเลือกได้เฉพาะ KPI ของแผนกเดียวกัน
- บันทึกแท็กในธุรกรรม ตรวจการแก้พร้อมกัน ป้องกันแท็กซ้ำ และอ่านกลับหลังบันทึก
- หน้ารายงานแสดงหลักฐานตามสิทธิ์ ไม่ตีความจำนวนแท็กเป็นคะแนน และแสดงว่ายังไม่มีผลจริงแทนคะแนนศูนย์
- การกรอกปัญหาใหม่และปิดเคสยังบังคับข้อมูลและสิทธิ์หัวหน้า เตรียมข้อยกเว้นเฉพาะ database owner ที่ไม่มี app session สำหรับนำเข้าประวัติจากต้นทางที่ระบุ
- ผ่าน prototype regression 57 checks, native entry validation, KPI UI workflow และฐานข้อมูลจำลอง staff/lead/admin รวม KPI ทั้ง 4 ประเภท
- ยังไม่ได้ทดสอบการแท็กผ่าน Production ด้วยบัญชีพนักงานจริง และยังไม่ได้ deploy โค้ดชุดนี้
